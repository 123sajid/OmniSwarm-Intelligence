# OmniSwarm AI: Frontend Dashboard 🧪✨
### **Premium Glassmorphic Dashboard for Multi-Agent Swarm Intelligence**

This is the interactive client for the **OmniSwarm AI** platform. It provides a real-time, data-dense interface designed with **modern glassmorphism**, animated sidebars, and an **Intelligence Feed** that monitors swarm activity concurrently.

---

## **🚀 Key UI Features**
- **Dynamic Swarm Visualization**: Real-time animated status bars for 5 specialized AI agents.
- **Emotion Radar 🧠**: Visual feedback from the metadata controller that adjusts based on user sentiment.
- **Intelligent Search 🔍**: Instant, semantic-ready filtering of chat records.
- **Restore Logic 📂**: Capability to pull archived conversations back into the active "Swarm Thinking" context.
- **Glassmorphic Theme**: Custom CSS 2.0 theme optimized for high-performance visual fidelity.

---

## **🚥 Quick Start (Local)**
Ensure Node.js (v18+) is installed.

```bash
# Install UI dependencies
npm install

# Start the dashboard (Port 5176)
npm run dev -- --port 5176
```

---

## **🛠️ Tech Stack**
- **React (Vite)**: Ultra-fast Hot Module Replacement (HMR).
- **Framer Motion**: Smooth, high-performance UI transitions and animations.
- **Lucide React**: Vector-optimized iconography.
- **Axios**: Promised-based HTTP client for swarm backend integration.
- **React Markdown**: Professional rendering of AI-generated insights.
